# مِرْصاد MIRSAD

منصة عربية للبحث والتحقيق، تعمل محلياً أولاً باستخدام IndexedDB عبر Dexie. الواجهة من اليمين إلى اليسار.

## التشغيل

يتطلب المشروع Node.js بإصدار 18 أو أحدث وnpm. بعد إضافة صفحات الأقسام المذكورة أدناه:

1. ثبّت الاعتماديات: `npm install`
2. شغّل بيئة التطوير: `npm run dev`
3. افتح العنوان الذي يعرضه Vite في المتصفح.
4. للتحقق من الأنواع وبناء نسخة الإنتاج: `npm run build`

صفحات الأقسام ليست ضمن هذا الأساس؛ لن يكتمل تشغيل التطبيق أو بناؤه قبل إضافتها. عند نشر نسخة الإنتاج، يجب إعداد الخادم لإعادة المسارات غير المطابقة إلى `index.html` لدعم React Router.

## ملكية الملفات

يتولى قائد التكامل إعدادات المشروع والتوجيه والغلاف العام، وله وحده تعديل `src/types/domain.ts` و`src/db/db.ts`. يعمل مهندس كل قسم داخل مجلده فقط، ويصدر الصفحة المحددة تصديراً افتراضياً:

| القسم | ملف الصفحة |
| --- | --- |
| لوحة التحكم | `src/features/dashboard/DashboardPage.tsx` |
| المكتبة | `src/features/library/LibraryPage.tsx` |
| التحقيقات | `src/features/investigations/InvestigationsPage.tsx` |
| الخط الزمني | `src/features/timeline/TimelinePage.tsx` |
| العلاقات | `src/features/relations/RelationsPage.tsx` |
| المساعد | `src/features/assistant/AssistantPage.tsx` |
| التقارير | `src/features/reports/ReportsPage.tsx` |

يمكن لمهندسي الأقسام استيراد الأنواع والمخططات من `src/types/domain.ts` ومثيل قاعدة البيانات `db` من `src/db/db.ts`. تُنسّق التغييرات المطلوبة على العقد المركزي مع قائد التكامل.

## عقد البيانات المحلي

- المعرّفات UUID نصية؛ يمكن إنشاؤها باستخدام `crypto.randomUUID()` في سياق آمن.
- حقول الوقت نصوص ISO 8601 بتوقيت UTC؛ يمكن إنشاؤها باستخدام `new Date().toISOString()`.
- تحقّق من البيانات بمخطط Zod المقابل قبل كتابتها. Dexie لا يطبّق المخططات تلقائياً.
- حقول الربط هي معرّفات سجلات؛ IndexedDB لا يفرض سلامة المراجع أو الحذف المتسلسل، لذا يجب معالجة ذلك في عمليات الأقسام.
- جدول `auditLogs` متاح للتسجيل، ولا تُنشأ سجلات التدقيق تلقائياً.
- البيانات محفوظة في المتصفح على الجهاز الحالي، وقد يؤدي مسح بيانات الموقع إلى حذفها. لا يتضمن الأساس مزامنة أو نسخاً احتياطياً تلقائياً.
